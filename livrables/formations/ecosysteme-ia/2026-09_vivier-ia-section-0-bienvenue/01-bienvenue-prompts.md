## Chapitre 3 — Installer votre assistant personnel

### Démarrer ton assistant personnel

Une seule commande, dans un dossier neuf dédié à ton assistant (pas dans un projet client existant) :
```
/install module-installs/kit-starter-vivier-academies
```
Claude Code lit le module et démarre l'interview de 5 questions. Le détail exact de ce que fait cette commande est dans `module-installs/kit-starter-vivier-academies/INSTALL.md`, si tu veux le lire avant de lancer.

### Recharger ton assistant en début de session

À utiliser à chaque nouvelle session, une fois les fichiers créés :
```
Lis CLAUDE.md, context/CONTEXT.md et context/HISTORY.md en entier.
Résume-moi en quelques lignes qui je suis, où j'en suis dans la
formation Vivier IA, et ce qui s'est passé lors de ma dernière session.
Attends ensuite mes instructions, ne lance rien de toi-même.
```

---

## Exercice pour l'apprenant

Une fois ton assistant installé, ouvre les trois fichiers créés et lis-les entièrement. Corrige à la main tout ce qui ne te représente pas fidèlement, avant de continuer vers le Module 1. Un assistant mal renseigné dès le départ garde cette imprécision à chaque session suivante, autant la corriger maintenant qu'elle est facile à repérer.
