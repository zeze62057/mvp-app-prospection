# Diapositives : Le terminal et l'IDE, votre nouvel espace de travail

6 diapositives. Elles servent d'ouverture, de repères et de récapitulatif : l'essentiel de la vidéo se passe à l'écran, dans VS Code et son terminal. Les numéros suivent le script (`01-script.md`).

## Plan

| N° | Apparaît à | Titre | Texte exact sur la diapositive |
|---|---|---|---|
| 1 | 0:00 | Le terminal et l'IDE, votre nouvel espace de travail | **Module 1, Section 1, Chapitre 2.** Objectif : ouvrir le terminal et l'IDE côte à côte, puis lancer Claude Code. Plan : 1. Le terminal. 2. L'IDE. 3. L'installation. |
| 2 | 0:22 | Deux outils, deux rôles | **Le terminal** : diriger l'agent. Vous écrivez, Claude Code agit et vous montre ce qu'il a fait. **L'IDE** : inspecter le projet. Fichiers, dossiers et changements, vus en contexte. |
| 3 | 1:20 | La bonne pratique | Le terminal pour diriger l'agent. L'IDE pour inspecter ce qu'il produit. Pas besoin d'écrire du code dans l'IDE. Il suffit de savoir vous y repérer. |
| 4 | 1:42 | Un exemple | **Dans le terminal** : vous écrivez, Claude décrit, il agit. **Dans l'IDE** : vous ouvrez, vous voyez, vous validez. Vous lisez, puis vous validez ou vous corrigez. |
| 5 | 2:09 | Installer votre poste de travail en trois étapes | 1. `code.visualstudio.com` (Visual Studio Code, gratuit). 2. Terminal intégré : menu Terminal, puis New Terminal, ou `` Ctrl+` `` (Windows, Linux), `` Cmd+` `` (Mac). 3. Extension `Claude Code`, dans l'onglet Extensions. |
| 6 | 5:13 | À retenir | Le terminal pour diriger, l'IDE pour inspecter. Le terminal : le canal de conversation et d'action. L'IDE : la fenêtre d'inspection visuelle du projet. Se repérer suffit : inutile d'écrire le code vous-même. **Prochaine vidéo** : Git et GitHub, le filet de sécurité du code. |
