# Enregistrement et mise en ligne : Le terminal et l'IDE, votre nouvel espace de travail

Module 1, section 1, chapitre 2. Voir `01-script.md` et `02-diapositives.md`.

## 1. Checklist d'enregistrement

**La veille**
- Lire le script une fois à voix haute, chronomètre en main. Corriger le débit réel par rapport aux 140 mots par minute prévus.
- Tester le diaporama en mode présentation, avec les clics : `diapositives-chapitre-2.pptx`, 12 clics en tout.
- Créer un dossier de démonstration vide et court, par exemple `C:\demo2`. Un chemin court évite d'afficher votre nom d'utilisateur Windows.
- Vérifier que Claude Code est installé (`claude --version`), puisque le chapitre 1 l'a installé.
- **Tester le raccourci du terminal sur votre clavier AZERTY.** Si `Ctrl` et l'accent grave ne s'ouvrent pas facilement, ne le citez pas comme un geste rapide : gardez le menu Terminal, puis New Terminal.
- Décider de l'état de départ de VS Code : soit il est déjà installé, et vous montrez seulement la page de téléchargement ; soit vous l'installez à l'écran (à couper au montage). Même choix pour l'extension Claude Code : montrez sa fiche, sans cliquer sur Installer si elle l'est déjà.

**Juste avant**
- Couper les notifications (assistant de concentration de Windows), fermer les onglets et applications inutiles.
- Écran en 1920 par 1080, bureau propre.
- VS Code : agrandir la police (Ctrl et `+`) et celle du terminal intégré, pour que tout se lise en 1080p.
- Fermer les autres dossiers récents de VS Code, pour ne pas afficher d'autres projets dans la liste d'accueil.
- Son : casque ou micro de qualité, pièce calme, test de une minute réécouté avant de commencer.

**Pendant**
- Dire à l'oral ce que vous faites avant de le faire.
- Laisser le terminal intégré s'ouvrir en bas, puis montrer côte à côte l'explorateur de fichiers et le terminal : c'est l'image à retenir de la vidéo.
- Ne demandez rien de plus à Claude Code que de démarrer : ce genre de demande de démonstration n'est pas dans le cours (voir le point 2 de la section « Points à valider » du script).

## 2. Vérification des secrets, avant de lancer l'enregistrement

Rien de ceci ne doit apparaître à l'écran :
- une clé d'API, un mot de passe ou un jeton, y compris ceux de Chatllow, de Chariow ou d'un client ;
- un fichier `.env` ouvert dans l'éditeur ;
- l'adresse e-mail de votre compte à l'écran de connexion de Claude Code : utilisez un compte de démonstration, ou floutez-la au montage ;
- votre nom d'utilisateur dans un chemin de dossier (barre de titre de VS Code, invite du terminal) ;
- une donnée client réelle, dans un onglet, un fichier récent, la liste « Ouvrir récent » de VS Code ou le presse-papiers.

Vérifiez aussi la barre d'onglets du navigateur, les favoris et l'historique du terminal.

## 3. Quel outil pour enregistrer

**Attention : l'outil d'enregistrement intégré à la plateforme ne convient pas pour une voix off.** Il capture l'écran et le son du système, mais pas le micro. Enregistrez avec un logiciel qui capte le micro (OBS Studio est gratuit), puis envoyez le fichier sur la plateforme.

Enregistrez tout l'écran en une seule prise. Le montage se limite aux coupures d'attente, par exemple un téléchargement.

## 4. Fiche à coller sur la plateforme

**Titre** : Le terminal et l'IDE, votre nouvel espace de travail

**Description** : Découvrez les deux outils de votre poste de travail avec Claude Code : le terminal, pour diriger l'agent, et l'IDE, pour inspecter ce qu'il produit. Puis installez Visual Studio Code, ouvrez le terminal intégré et ajoutez l'extension Claude Code.

**Points clés**
- Le terminal est le canal de conversation et d'action avec l'agent.
- L'IDE est la fenêtre d'inspection visuelle du projet.
- Se repérer suffit : pas besoin d'écrire le code vous-même.
- Installation : Visual Studio Code, terminal intégré, extension Claude Code.

**Durée** : à renseigner après l'enregistrement (estimation : 5 min 35 s avant montage).
