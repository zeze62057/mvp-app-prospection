# Ressources plugins

Ressource partagée pour le chapitre 3 de la section 7 du Module 1 (« Plugins et Extensions »). Un seul plugin a été réellement installé depuis le début de la préparation de cette formation : [ponytail.md](ponytail.md). Pas d'exemple inventé, seulement ce qui a réellement été fait, avec la vérification qui a précédé l'installation.

## Pourquoi un seul plugin ici

Les autres extensions visibles dans un `claude plugin list` de ce poste (Canva, Notion, n8n, et une vingtaine d'autres) sont des connecteurs synchronisés depuis le compte claude.ai de Zézé, pas des plugins installés pour cette formation. Ils sont propres à son compte : un élève ne les retrouvera pas en l'état sur le sien, ils ne sont donc pas une ressource pédagogique reproductible. Seul Ponytail a été installé, vérifié et documenté volontairement, dans cette session de travail.

## À faire quand un autre plugin sera installé

Ajouter un fichier `<nom-du-plugin>.md` dans ce dossier, sur le même modèle que `ponytail.md` : ce qu'il fait, ce qui a été vérifié avant de l'installer, comment l'installer, comment le désactiver. Ne jamais documenter un plugin qui n'a pas été réellement testé dans ce workspace.
