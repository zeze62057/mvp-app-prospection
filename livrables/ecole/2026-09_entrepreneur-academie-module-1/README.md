# Module 1 — Écosystème Claude

> Matériel pédagogique pour Entrepreneur Académie, rédigé par Claude à partir de la table des matières du skill `programme-ecosysteme-ia`. Contenu de cours original (pas une copie d'un cours existant), à ajuster par Zézé avant utilisation avec de vrais apprenants.

**Objectif du module (rappel du programme source) :** à la fin, livrer des produits complets à des clients, du terminal au déploiement, et faire de chaque projet un starter réutilisable et revendable.

## Sommaire

1. [Les Fondations](01-fondations.md) — pourquoi Claude Code change le métier, terminal et IDE, Git/GitHub, Vercel et OVH
2. [La Méthode](02-methode.md) — Agentic Coding vs Vibe Coding, donner des instructions, workflow Plan/Execute/Validate, débogage
3. [Maîtriser l'outil](03-maitriser-loutil.md) — premiers pas, CLAUDE.md, Skills et Slash Commands, MCP, Hooks, structure de projet, coûts
4. [Claude Code au quotidien](04-quotidien.md) — Second Brain, livrables professionnels, gérer son business
5. [Le Fullstack, projet fil rouge](05-fullstack-fil-rouge.md) — de Lovable à Claude Code, architecture n8n + Claude Code, MCP Playwright, 3 phases de build
6. [Le Business](06-business.md) — livraison client, maintenance, ce qu'on vend, bibliothèque de starters
7. [Hacks & vidéos bonus](07-hacks-bonus.md) — sub-agents avancés, Claude Code au-delà de n8n, plugins et extensions

## Comment ce module est construit

Chaque chapitre a : une leçon en profondeur, des points clés à retenir, et des questions pour les apprenants (compréhension + réflexion) en fin de section, avec des éléments de correction réservés à l'enseignant.
