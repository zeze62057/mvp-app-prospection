# ecole/

Livrables pour Vivier IA (école de l'IA en francophonie, anciennement "Entrepreneur Académie").

## Organisation

Deux filières de modules, dans leur propre sous-dossier :

- **`ecosysteme-ia/`** — les modules sur l'écosystème Claude (Module 1 : Écosystème Claude, Module 2 : n8n, et les modules suivants du programme de référence : Mindset & Business IA, RGPD/AI Act, Lemlist)
- **`marketing-reseau/`** — le programme marketing de réseau complet et le module croisé "IA appliquée au marketing de réseau" pour les distributeurs Longrich

L'identité visuelle de l'école (`2026-09_vivier-ia-identite-visuelle/`) reste à la racine de `ecole/`, ce n'est pas un module de cours.

## Ce qu'on met ici

- Programmes et syllabus de formation
- Modules de cours, supports, slides
- Exercices, cas pratiques, quiz, corrigés
- Scripts de vidéos pédagogiques
- Parcours apprenants, plans de certification
- Contenus pour distributeurs Longrich formés à l'IA

## Ce qu'on ne met pas ici

- Le site ou la plateforme LMS, ils vont dans `sites-web/`
- Les outils pédagogiques applicatifs, ils vont dans `applications/`

## Nommage

Un module ou un parcours par sous-dossier, dans la filière concernée : `ecosysteme-ia/AAAA-MM_nom-du-module/` ou `marketing-reseau/AAAA-MM_nom-du-module/`
Exemple : `ecosysteme-ia/2026-11_module-3-mindset-business-ia/`
