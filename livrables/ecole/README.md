# ecole/

Dossier provisoire. Les livrables de l'école de l'IA vivent désormais dans `livrables/vivier-ia/`.

## Ce qu'il reste ici

- **`marketing-reseau/`** : le programme marketing de réseau (50 chapitres) et le module croisé "IA appliquée au marketing de réseau" pour les distributeurs Longrich

Leur emplacement définitif (`longrich/`, `vivier-ia/cours/` ou un dossier dédié) n'est pas encore tranché. Tant que c'est le cas, ne pas les déplacer : le skill `approche-ia-marketing-reseau` et une migration de la plateforme Vivier référencent ces chemins.
