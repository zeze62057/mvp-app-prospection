## Ce qu'on met ici

- Applications, SaaS et plateformes sur l'écosystème Claude
- Scripts (Python, JS, Bash, PowerShell) et petits utilitaires
- Automatisations et workflows (veille, publication, reporting)
- Bots, intégrations API, connecteurs

## Ce qu'on ne met pas ici

- Les pages web publiques sans logique applicative, elles vont dans `sites-web/`
- Les logos et chartes graphiques, ils vont dans `identites-visuelles/`
- Les cours et supports de formation, ils vont dans `formations/`

## Nommage

Un projet par sous-dossier : `AAAA-MM_nom-du-projet/`, avec un `README.md` (but, prérequis, comment lancer).
Exemple : `2026-09_bot-veille-actus/`
