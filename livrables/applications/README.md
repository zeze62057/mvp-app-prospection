# applications/

Outils, scripts et automatisations produits par Claude.

## Ce qu'on met ici

- Scripts (Python, JS, Bash, PowerShell) et petits utilitaires
- Automatisations et workflows (veille, publication, reporting)
- SaaS et applications sur l'écosystème Claude
- Bots, intégrations API, connecteurs
- Prototypes d'outils sans interface web publique

## Ce qu'on ne met pas ici

- Les sites et pages web publiques, ils vont dans `sites-web/`
- Les briefs produit et specs non accompagnés de code, ils vont dans le dossier thématique concerné

## Nommage

Un projet par sous-dossier : `AAAA-MM_nom-de-l-outil/`
Exemple : `2026-09_bot-veille-actus/`

Ajouter un `README.md` dans chaque projet avec : but, prérequis, comment lancer.
