# sites-web/

Sites internet et pages web publiques produits par Claude.

## Projets

| Dossier | Contenu |
|---------|---------|
| `2026-09_landing-vivier-ia/` | Landing page publique de Vivier IA (anciennement `landing-entrepreneur-academie`) |
| `2026-09_portail-academie/` | Portail existant, à archiver ou rediriger une fois la vitrine de Vivier Academies construite (décision du 2026-09-13) |

## Ce qu'on met ici

- Sites vitrines (cabinet Chatllow, école, chaîne YouTube)
- Landing pages et pages de capture
- Portfolios, mini-sites d'événement
- Maquettes HTML/CSS, prototypes de pages

## Ce qu'on ne met pas ici

- Les applications avec une vraie logique (comptes, base de données, paiement), elles vont dans `applications/`
- Les logos et chartes, ils vont dans `identites-visuelles/`

## Nommage

Un projet par sous-dossier : `AAAA-MM_nom-du-site/`
Exemple : `2026-09_landing-cabinet-chatllow/`
