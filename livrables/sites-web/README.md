# sites-web/

Sites internet et pages web produits par Claude.

## Ce qu'on met ici

- Sites vitrines (cabinet Chatllow, Entrepreneur Académie, chaîne YouTube)
- Landing pages et pages de capture
- Portfolios, mini-sites d'événement
- Maquettes HTML/CSS, prototypes de pages
- Code source front (HTML, CSS, JS, frameworks) d'un site

## Ce qu'on ne met pas ici

- Les outils et scripts sans interface web publique, ils vont dans `applications/`
- Les documents de brief ou de contenu texte non intégrés, ils vont dans le dossier thématique concerné

## Nommage

Un projet par sous-dossier : `AAAA-MM_nom-du-site/`
Exemple : `2026-09_landing-cabinet-chatllow/`
